# 🚀 Number Operations Web App

A modern and interactive Number Operations Calculator built using **HTML, CSS, and JavaScript**. This application allows users to perform common number-based operations with a beautiful glassmorphism UI, smooth animations, and dark mode support.

## 🌐 Live Demo

🔗 [**Live Demo**](https://durgaprasadcodes.github.io/Number-Operations/)

---

## ✨ Features

### 🧮 Factorial Calculator

Calculate the factorial of any non-negative integer.

### 🔢 Fibonacci Generator

Generate Fibonacci sequences up to the specified number of terms.

### 🔍 Prime Number Finder

Display all prime numbers from 2 up to the entered value.

### 🔁 Palindrome Checker

Verify whether a number is a palindrome.

### 🌙 Dark Mode

Toggle between light and dark themes for an enhanced user experience.

### 🎨 Modern UI

* Glassmorphism design
* Responsive layout
* Smooth animations
* Mobile-friendly interface

## ⚙️ How It Works

### Factorial

Computes:

```text
n! = n × (n-1) × (n-2) × ... × 1
```

### Fibonacci

Generates:

```text
0, 1, 1, 2, 3, 5, 8, ...
```

### Prime Numbers

Finds all numbers divisible only by 1 and themselves.

### Palindrome

Checks whether:

```text
121 → Palindrome ✅
123 → Not Palindrome ❌
```
